# Actividad1_KinalApp
Es una API REST desarrollada con Spring Boot que permite gestionar clientes, productos, ventas y sus detalles, realizando operaciones de crear, consultar, actualizar y eliminar datos en una base de datos MySQL.

# Descripción

API REST desarrollada con Spring Boot para la gestión de:

- Clientes
- Productos
- Ventas
- Detalle de Venta

# Tecnologías

- Java
- Spring Boot
- JPA / Hibernate
- MySQL
- Postman

# Endpoints principales

# Cliente

- GET /api/clientes
- POST /api/clientes
- PUT /api/clientes/{id}
- DELETE /api/clientes/{id}

# Producto

- GET /api/productos
- POST /api/productos
- PUT /api/productos/{id}
- DELETE /api/productos/{id}

# Venta

- GET /api/ventas
- POST /api/ventas
- PUT /api/ventas/{id}
- DELETE /api/ventas/{id}
