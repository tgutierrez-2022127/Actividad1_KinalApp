# Actividad1_KinalApp

Es una API REST desarrollada con Spring Boot que permite gestionar clientes, productos, ventas y sus detalles, realizando operaciones de crear, consultar, actualizar y eliminar datos en una base de datos MySQL.

---

## Descripcion

API REST desarrollada con Spring Boot para la gestion de:

- Clientes
- Productos
- Ventas
- Detalle de Venta

---

## Tecnologias

- Java
- Spring Boot
- JPA / Hibernate
- MySQL
- Postman
- Thymeleaf (Motor de plantillas HTML)

---
